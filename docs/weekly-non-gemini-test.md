# 週次プロトタイプ（Geminiなし）受け入れテスト v0.2

## 完成デモ（API通信ゼロで通ること）
1. 空の専用テスト保存領域で始め、サンプルの数値が今週の実統計に含まれない。
2. 手入力で会話Aを今週の「壁打ち」720秒、**費用**として保存する。
3. 手入力で会話Bを今週の「文章作成」1080秒、**成果物資産**として保存する。
4. 同じ `id` もしくは同じ取り込みイベントを再登録しても、重複の3件目が発生しない。
5. 今週の総時間1800秒=30分、費用720秒、資産1080秒、仕掛0秒、未分類0秒、記録2件となる。
6. 「AI仮受品/時間拠出」仮計上と確定振替で全仕訳の借方=貸方。週次のB/S・P/Lも定義通りに整合する。
7. 思考レシートでは**「AI分析未接続」**と表示され、3指標は0点ではなく未評価。本人が手動で発見と判断を入力して保存できる。
8. 週次振り返り（発見2件、次週目標）を確定し、再読み込みして保持される。
9. Aの利用秒数を修正しても計算が再実行され、帳簿に二重計上しない。Aを削除すると週次集計も減る。
10. `time-only` は本文を保存しない。`off` は時間も本文も保存しない。保存失敗時は成功と表示しない。
11. 前週/今週を切り替え、月末・年末・月曜0時の境界で時間が正しい週に入る。
12. Chrome拡張から取得できる会話を確認・保存できる（拡張変更後は実機で確認）。拡張で計測していない手入力秒数を「実測」と表示しない。
13. 研究モードで事前AIASレベルを登録し、レシートに表示される。AIASレベルを成長スコアとして平均しない。
14. 自動分析が未接続でも、週次決算を最後まで操作できる。
15. ブラウザからGemini、他の外部AI APIへ**本担当コードが通信しない**（既存通信があれば状況報告）。APIキー/SDK/プロキシの新規実装はない。

## 自動テスト必須
- 秒数: 整数・非負・空値・負数・小数、週跨ぎ分割、二重登録防止、保存/更新/削除。
- 会計: 取得時・分類時・修正時・削除時の借貸一致、総秒数の区分内訳一致、BS/PLの整合。
- 週期間: 月曜00:00、日曜23:59:59、年/期跨ぎ、日付不正、タイムゾーン、既存期間集計の回帰。
- プライバシー: full/time-only/offと後からの変更、本文削除、失敗時復旧。
- 旧データ保護: `ThoughtReceipt` と `IssuedThinkingReceipt` の旧保存領域を書き換えない。サンプル隔離。
- UI: 未接続分析の状態、本人メモ、空週、未分類、週の確定/再確定、画面幅320/390/768px。
- Chrome拡張: 会話取り込み失敗・本文欠落の扱い、計測/非計測の区別、タブ・アイドル・再起動（計測追加時）。
- API契約: 後でGemini担当者が結果を渡すための固定フィクスチャのスキーマテストだけ。本担当でHTTP呼び出しを作らない。

## Codexの報告項目
変更したファイル、手動の試験手順、`pnpm build` と既存・新規テストの実行結果、未確認事項、Gemini担当との調整項目、コミットする前に必要な確認事項。テスト用記録を実データに混ぜない。
