# 研究用・週次思考分析基準 v1

- 基準ID: `research-thinking-rubric-v1`
- 対象: 同意を得て送信された一つの活動の会話内行動
- 位置付け: AIASを参考にした研究独自の行動分析。AIAS公式評価でも、利用者の一般的な能力・成長の点数でもない。
- 原則: 本人の発言から直接確認できる短い引用がない場合は `null`。`null` は根拠不足で、0点とは異なる。0にも根拠が必要。

## 自発性

| 値 | 会話内で確認する暫定的な行動基準 |
|---:|---|
| 0 | AIの提案に従う発言だけがあり、目的・条件・次の行動を本人が示していない。 |
| 25 | 本人が依頼や関心を示すが、目的・条件・進め方の具体化はAI側に委ねている。 |
| 50 | 本人が目的または条件を示し、AIへの依頼や選択を一部具体化している。 |
| 75 | 本人が目的・条件・判断基準を示し、追加指示や方向修正を行っている。 |
| 100 | 本人が課題、検証手順、判断基準を主導して設計し、結論と次の行動を自ら決めている。 |

## 論理性

| 値 | 会話内で確認する暫定的な行動基準 |
|---:|---|
| 0 | 本人の結論や選択に、理由・関係・比較が示されていない。 |
| 25 | 本人が結論や希望を述べるが、根拠や比較の説明は限定的である。 |
| 50 | 本人が少なくとも一つの理由、条件、因果関係を示している。 |
| 75 | 本人が複数案・条件・利点と制約を比較し、選択理由を説明している。 |
| 100 | 本人が仮説、根拠、反例や不確実性を関連付け、検証可能な形で結論を組み立てている。 |

## 批判的判断

| 値 | 会話内で確認する暫定的な行動基準 |
|---:|---|
| 0 | 本人がAI出力を受け入れる発言だけで、確認・留保・修正がない。 |
| 25 | 本人が疑問や違和感を示すが、具体的な確認または修正には至っていない。 |
| 50 | 本人がAI出力の一部を確認、修正、採否判断している。 |
| 75 | 本人が根拠・出典・制約を確認し、AI案を比較して採用・修正・却下している。 |
| 100 | 本人が独立した検証を行い、AI出力の限界を明示したうえで判断理由と適用範囲を記録している。 |

## その他の抽出項目

- 活動テーマ、勘定科目、会計区分は候補として表示するだけで、自動仕訳や週次決算に反映しない。
- 実際のAIの役割・協働行動は、事前の期待役割やAIAS Levelとは分けて抽出する。
- 思考の変化・発見・学びは会話に明示された場合だけ記述し、推測で補わない。
- null以外の値と協働行動には、会話ID・メッセージ位置・実在する引用を必須とする。
- AIの元結果と本人の確認・修正値を別の保存領域に保持する。
