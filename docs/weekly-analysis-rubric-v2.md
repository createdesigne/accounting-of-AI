# 研究用思考分析ルーブリック v2（確定仕様）

- 基準ID: `research-thinking-rubric-v2`
- 指標: 自発性・論理性・独立性
- 点数: `0 / 25 / 50 / 75 / 100 / null`
- 状態: `confirmed / provisional / hold / not_applicable`

## 自発性

| 点 | 観察可能な行動 |
|---:|---|
| 0 | 思考を要する課題で、自分は考えず全てAIに任せると明示した。 |
| 25 | 自分の関心・話題は示すが、自ら理由を発展させずAIの答えにほぼ従う。 |
| 50 | AIの問いに対し、自分の仮説と理由を述べる。 |
| 75 | 自分から新しい視点や解決策を提示する。 |
| 100 | 自分の案の弱点を検討し、適切に発展・再構成する。 |

## 論理性

| 点 | 観察可能な行動 |
|---:|---|
| 0 | 中核の推論に決定的な矛盾など、十分に明確な重大問題がある。些細な誤りだけで0にしない。 |
| 25 | 結論を支える根拠が著しく弱い、または重要な論理飛躍がある。 |
| 50 | 主張と理由に基本的なつながりがある。 |
| 75 | 関連する反論・制約・リスクを検討して調整する。 |
| 100 | 課題の目的に必要十分な推論・重要条件・検証可能性を扱う。 |

## 独立性

| 点 | 観察可能な行動 |
|---:|---|
| 0 | 本人が担うべき判断を、検討せずAIに全面委任した証拠がある。 |
| 25 | 自分の関心を多少使うが、判断の大部分をAIに委ねる。 |
| 50 | 自分の価値観・条件を実際の判断や方向性に使う。 |
| 75 | 自分の基準で比較し、またはAI提案を吟味して方向性を修正する。 |
| 100 | 自分の目的から検討方向を主体的に定め、選択または理由ある判断保留を行う。 |

## 必須ルール

- 短文・1文字回答だけで低得点にしない。許可された前後文脈が不足すれば `hold` / `null`。
- 0点は「考えなかった証拠」がある場合だけ。単なる証拠不足は `hold` / `null`。
- 校正・翻訳など思考行動が目的に不要なら `not_applicable` / `null`。
- AIとの一致・不一致そのものは独立性の根拠にしない。
- 検討過程の独立性と最終判断の独立性を分離して記録する。
- 自己申告は `self_report`、会話から観察した行動は `observed_behavior` として区別する。
- 課題の客観的複雑さと本人の主観的難しさを分離し、思考点数へ加点しない。
- 同一発言を複数指標に使う場合、別々の観察可能な特徴を明記する。
- 長期比較は同じ目的・近い複雑さ・同一ルーブリックを原則とし、十分性不明なら `trend_hold` とする。

旧 `research-thinking-rubric-v1` の `criticalJudgment` は本ルーブリックの `independence` へ変換しない。
